Instructions
  1. Select a drawing tool from the control panel.
  2. Place a start point (green) and end point (yellow) on the grid.
  3. Draw walls/barriers (black) to block paths.
  4. Click "Start Algorithm" to visualize the A* pathfinding process.
  5. Use "Reset Grid" to clear everything or "Clear Path" to keep walls but remove the path.
  6. Right-click or use the Eraser tool to remove nodes.
About A* Pathfinding

A* (pronounced "A-star") is a popular pathfinding algorithm used in computer science and artificial intelligence. It efficiently plots the shortest path between two points by:

  • f(n) = g(n) + h(n): A* uses this formula to evaluate each node
  • g(n): Cost from start node to current node
  • h(n): Heuristic (estimated distance) from current node to goal
  • A* explores nodes with the lowest f-score first, making it both optimal and efficient

The visualization shows:

  • Blue nodes in the open set (to be evaluated)
  • Red nodes in the closed set (already evaluated)
  • Grey nodes in the final path once found
